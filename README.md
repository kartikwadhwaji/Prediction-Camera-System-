# Prediction-Camera-System-
AI-powered CCTV surveillance system that analyzes live video in real time using object detection, pose estimation, tracking, and face recognition. It identifies people, weapons, and suspicious behaviors, classifies risks as low/high/very high, and generates alerts, annotations, and logs, reducing false alarms and manual monitoring.
